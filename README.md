# Online4Tech Control Center
### لوحة التحكم الذكية والمتكاملة لأجهزة Enigma2
**ONLINE4TECH · خليك دايمًا أونلاين**

بلجن **Online4Tech Control Center** هو مركز تحكم محلي لأجهزة الاستقبال العاملة بنظام **Enigma2**. بيجمع أهم أدوات إدارة الرسيفر في واجهة ويب عربية واحدة، تقدر تفتحها من الموبايل أو الكمبيوتر على نفس شبكة المنزل، وتتحكم في خدمات الجهاز وتتابع حالته وتدير إعداداته وأدواته بدون الحاجة للتنقل بين قوائم الرسيفر في كل مرة.

المشروع مصمم ليكون خفيفًا ويعمل مباشرة على الرسيفر باستخدام Python الموجود بالنظام، مع واجهة عربية RTL وتصميم متجاوب مع الشاشات الكبيرة والموبايل.

---

## ✨ المميزات الرئيسية

### 1. لوحة متابعة حالة الرسيفر
تعرض اللوحة مؤشرات أساسية يتم تحديثها تلقائيًا:
- الإيمو النشط: OSCam أو NCam أو CCcam عند اكتشافه.
- استخدام ذاكرة RAM والنسبة المستخدمة.
- استهلاك مساحة الفلاش والمساحة المتاحة.
- درجة حرارة المعالج عند توفر حساس مدعوم في صورة النظام.

### 2. التحكم السريع في الجهاز
من مكان واحد تقدر تنفذ:
- إعادة تشغيل الإيمو.
- إعادة تشغيل واجهة Enigma2 بعد تأكيد العملية.
- إعادة تشغيل الرسيفر بالكامل بعد التأكيد.
- تحديث ملفات لوحة التحكم من مستودع GitHub الرسمي.

### 3. إدارة اشتراكات IPTV
- تثبيت إضافات XStreamity وXKlass وAJPanel وJediMakerXtream وفق مصادر التثبيت المضبوطة والمتاحة للجهاز.
- لصق رابط M3U كامل ومحاولة استخراج Host وUsername وPassword تلقائيًا.
- إنشاء باقات IPTV من نوع Live وVOD وSeries.
- اكتشاف إضافات IPTV المدعومة والمثبتة، ثم اختيار الإضافات المطلوب حفظ بيانات الاشتراك بها.

### 4. إدارة CCcam وملفات Readers
- لصق سطر CCcam كامل بصيغة C: لتعبئة البيانات تلقائيًا.
- إدخال Host وPort وUsername وPassword بشكل منفصل.
- حفظ بيانات CCcam في أحد المسارين:
  - `/etc/CCcam.cfg`
  - `/etc/tuxbox/config/CCcam.cfg`
- إنشاء Reader في ملف `ncam.server` أو `oscam.server`.

### 5. تثبيت وإدارة الإيموهات
توفير أزرار لتثبيت:
- OSCam
- NCam

تُحمّل سكريبتات التثبيت من المصادر المحددة داخل إعدادات المشروع، وتظهر نتيجة التنفيذ في سجل العمليات.

### 6. أدوات القنوات والبيكونات ودليل البرامج
تضم اللوحة اختصارات لتشغيل:
- تحديث ملف القنوات.
- تحديث البيكونات الخارجية على وحدة تخزين قابلة للكتابة.
- تحديث البيكونات الداخلية في مسار Enigma2.
- تحديث دليل البرامج الإلكتروني EPG.

**تحديث البيكونات الخارجية:** يبحث البلجن في وحدات التخزين المركبة تحت `/media`، ويتعامل مع المسارات الفعلية والروابط الرمزية مثل `/media/hdd` إذا كانت تشير إلى مسار آخر. يشترط توفر مساحة وكتابة، ويجهّز الملفات الجديدة قبل استبدال النسخة الحالية، مع الاحتفاظ بنسخة احتياطية عند نجاح الاستبدال. مصدر ملف ZIP الخارجي هو إصدار البيكونات المنشور في مستودع Online4Tech.

**تحديث البيكونات الداخلية:** يتحقق من إمكانية الكتابة والمساحة، ويجهّز الملفات قبل الاستبدال مع الاحتفاظ بالنسخة السابقة. مصدر الأرشيف الداخلي مضبوط بشكل مستقل عن مصدر البيكونات الخارجية.

### 7. مكتبة الأوامر والكتالوج
- تحميل كتالوج Online4Tech مباشرة من مستودع الكتالوج.
- تصفح العناصر حسب التصنيف والبحث بالاسم.
- تصنيفات تشمل البلجنات، الاسكينات، البيكونات، ملفات القنوات، الأدوات، المكتبات، وصور الأنظمة المتاحة في الكتالوج.
- اختصارات لتحديث قائمة البيكونات، عرض المكتبات الناقصة المتوافقة، تحديث فهارس الحزم، واستعراض ملفات القنوات وصور الأنظمة.
- يتم إخفاء المكتبات التي لا تتوافق مع إصدار Python المكتشف على الرسيفر.

**مهم:** اختيار عنصر من المكتبة يضع أمر التثبيت في مربع التيرمنال فقط. لا يتم تنفيذ الأمر تلقائيًا؛ التنفيذ لا يبدأ إلا بعد الضغط على زر «تنفيذ الأمر». بعض أوامر صور الأنظمة وملفات الإقلاع تعرض تحذيرًا قبل تجهيز الأمر.

### 8. تيرمنال مباشر وسجل العمليات
- تنفيذ أوامر النظام من واجهة الويب.
- دعم إدخال أكثر من سطر.
- عرض مخرجات الأوامر ورسائل النجاح والأخطاء في سجل واضح.
- مسح سجل العمليات عند الحاجة.

التيرمنال أداة قوية وتنفذ الأوامر بصلاحيات المستخدم الذي يشغّل البلجن على الرسيفر؛ استخدم الأوامر التي تفهمها فقط.

## ⚙️ طريقة عمل البلجن

1. يتم تثبيت ملفات البلجن داخل مجلد إضافات Enigma2:
   `/usr/lib/enigma2/python/Plugins/Extensions/OnlineWebControl/`
2. من قائمة البلجنات افتح **Online4Tech Control Center**.
3. اضغط الزر الأخضر لفتح بوابة لوحة الويب (المنفذ **7070**)، أو الأحمر لقفلها. الكارت الكبير بيعرض الحالة: مفتوحة / مقفولة.
4. يعرض البلجن عنوان IP الخاص بالرسيفر.
5. افتح متصفح الموبايل أو الكمبيوتر المتصل بنفس الشبكة واكتب:
   `http://RECEIVER-IP:7070`
   واستبدل `RECEIVER-IP` بعنوان IP الظاهر على شاشة البلجن.
6. تتواصل الواجهة مع خادم Python المحلي عبر واجهات API داخل الرسيفر. الخادم يقرأ بيانات الحالة وينفذ الوظائف المطلوبة ويعيد النتيجة إلى المتصفح.
7. الزر الأصفر داخل شاشة البلجن ينزّل ملفات الإصدار الأخير من GitHub، ويتحقق من سلامة ملفات Python قبل استبدال الملفات المثبتة، ويحتفظ بنسخ مؤقتة للاسترجاع عند فشل التحديث، ثم يطلب إعادة تشغيل واجهة Enigma2 فقط.

### أزرار الريموت
| الزر | الوظيفة |
|---|---|
| الأخضر | تشغيل لوحة الويب |
| الأحمر | إيقاف لوحة الويب |
| الأصفر | تحديث البلجن وإعادة تشغيل واجهة Enigma2 |
| الأزرق | شاشة شرح دور البلجن وطريقة التشغيل |
| OK | تحديث حالة التشغيل وعنوان IP |
| EXIT | إغلاق شاشة البلجن |

## 📥 التثبيت من خلال Telnet

اتصل بالرسيفر من Telnet باستخدام بيانات الدخول المعتادة، ثم نفّذ الأمر التالي كما هو:

```sh
wget -qO- https://raw.githubusercontent.com/online4tech/webcontrol1/main/install.sh | sh
```

يقوم المثبّت بتنزيل ملفات البلجن من المستودع الرسمي، والتحقق من وجود Python، ثم نسخ الملفات إلى مجلد الإضافات. بعد اكتمال التثبيت يجدول إعادة تشغيل **واجهة Enigma2 فقط** حتى يظهر البلجن في قائمة الإضافات؛ لا يقوم الأمر بعمل إعادة تشغيل كاملة للرسيفر.

بعد عودة الواجهة:
1. افتح قائمة Plugins.
2. شغّل **Online4Tech Control Center**.
3. اضغط الأخضر لتشغيل اللوحة.
4. افتح عنوان IP الظاهر على الشاشة مع المنفذ `7070` من جهاز متصل بنفس الشبكة.

> **ملاحظة:** لا تغلق اتصال Telnet أثناء تنفيذ التثبيت، وانتظر رسالة `Installation complete.` قبل انتهاء العملية.

## 🔄 التحديث

**من داخل الرسيفر:** افتح البلجن واضغط الزر الأصفر. سيقوم البلجن بجلب الملفات الأحدث من فرع `main` في مستودع GitHub الرسمي، ثم يعيد تشغيل واجهة Enigma2 بعد نجاح التحديث.

**من Telnet:** يمكن إعادة تشغيل أمر التثبيت نفسه لتنزيل ملفات الإصدار الحالي وتثبيتها:

```sh
wget -qO- https://raw.githubusercontent.com/online4tech/webcontrol1/main/install.sh | sh
```

## 🔐 الأمان والخصوصية

- اللوحة لا تتطلب اسم مستخدم أو كلمة مرور في الإعداد الحالي.
- الوصول مخصص للشبكة المحلية فقط.
- أي جهاز متصل بنفس الشبكة المحلية ويمكنه الوصول إلى عنوان الرسيفر والمنفذ `7070` يستطيع استخدام وظائف التحكم، بما فيها التيرمنال.
- **لا تفتح المنفذ 7070 على الإنترنت، ولا تعمل له Port Forwarding، ولا تستخدم اللوحة على شبكة عامة أو غير موثوقة.**
- لا تشارك رابط اللوحة مع أشخاص غير موثوقين.

- بعض الوظائف تعتمد على صورة النظام ومصادر الحزم ومسارات الملفات المتاحة على الجهاز؛ لذلك قد تختلف نتيجة التثبيت من صورة Enigma2 لأخرى.

## 📁 ملفات المشروع

| الملف | الاستخدام |
|---|---|
| `plugin/plugin.py` | شاشة البلجن وأزرار الريموت وتشغيل/إيقاف/تحديث اللوحة |
| `plugin/online_web_control.py` | خادم الويب والواجهة وواجهات API ووظائف الإدارة |

## 🛠️ تطوير المشروع

1. يتم تعديل الملفات المطلوبة داخل مجلد `plugin/`.
2. تُراجع التغييرات ويُتحقق من صياغة ملفات Python.
3. تُرفع التعديلات إلى فرع `main`.
4. يتم تحديث رقم `VERSION` عند إصدار نسخة جديدة.
5. GitHub Actions ينفذ فحص Python ويبني حزمة IPK قابلة للتنزيل كـ Artifact.
