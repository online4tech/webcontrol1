# Online4Tech Control Center

بلجن Enigma2 بواجهة عربية تحمل هوية **ONLINE4TECH · ONLINE TECHNOLOGY**، مع لوحة ويب محلية على المنفذ **7070**.

## التثبيت والتحديث
نفّذ الأمر التالي من Telnet على الرسيفر:

```sh
wget -qO- https://raw.githubusercontent.com/online4tech/webcontrol1/main/install.sh | sh
```

بعد تثبيت الملفات، يعيد السكريبت تشغيل واجهة Enigma2 تلقائيًا (وليس الرسيفر بالكامل).

## واجهة البلجن على الرسيفر
من قائمة البلجنات افتح **Online4Tech Control Center**:

- الزر الأخضر: تشغيل لوحة الويب.
- الزر الأحمر: إيقاف لوحة الويب.
- الزر الأصفر: تنزيل آخر ملفات البلجن واللوحة من مستودع GitHub الرسمي، والتحقق من ملفات Python قبل استبدالها، ثم إعادة تشغيل واجهة Enigma2.
- زر OK: تحديث حالة التشغيل وعنوان IP.
- زر EXIT: إغلاق الواجهة.

## لوحة الويب
افتح من متصفح على نفس الشبكة:

`http://IP-الرسيفر:7070`

تحتوي اللوحة على إدارة IPTV وملفات القنوات والإيموهات وبيانات CCcam وسجل الأوامر. تم ترتيبها في عمودين على الشاشات الكبيرة وعمود واحد على الموبايل.

## رفع تحديث جديد
1. عدّل الملفات داخل `plugin/`.
2. ارفع الملفات المعدّلة إلى فرع `main`.
3. حدّث رقم الإصدار في `VERSION` مع كل إصدار جديد.
4. بعد نشر التعديلات، استخدم الزر الأصفر من البلجن لسحب النسخة الجديدة.

الملفات التي يسحبها زر التحديث:
- `plugin.py`
- `online_web_control.py`
- `__init__.py`
- `VERSION`

## الأمان
لا توجد كلمة مرور؛ الاستخدام داخل الشبكة المحلية فقط. أي جهاز على نفس الشبكة يمكنه التحكم في الرسيفر، لذلك لا تفتح أو تحوّل المنفذ **7070** إلى الإنترنت.
